# 台灣用語對照表

本檔案是 `SKILL.md` §11 的完整參考。需要確認個別術語時讀取本檔案。

**使用方式**：左欄為中國慣用語，右欄為台灣慣用語。寫作時使用右欄；審查時搜尋左欄。

左右欄相同的列（如 `密碼 | 密碼`）代表該詞台灣與中國寫法一致，列在表中是為了避免審查時被誤判為需要修正；搜尋左欄命中這類詞時不必改寫。

## 1. 同形異義詞（優先確認）

以下詞在台灣與中國都存在，但意思不同。字形是繁體、拼寫也正確，只有語意錯誤，因此最難察覺。

| 詞 | 台灣語意 | 中國語意 | 台灣對應寫法 |
|---|---|---|---|
| 文件 | document | file | file → 檔案 |
| 文檔 | （不使用） | document | document → 文件 |
| 質量 | mass（物理量） | quality | quality → 品質 |
| 項目 | item、款項 | project | project → 專案 |
| 程序 | procedure、法律程序、開機程序 | program | program → 程式 |
| 登錄 | 登記、記錄 | login | login → 登入 |
| 數據 | 量測數值 | data | data → 資料 |
| 信息 | （少用） | information、message | information → 資訊；message → 訊息 |
| 智能 | （少用） | intelligence | intelligence → 智慧 |
| 屏 | 屏障 | screen | screen → 螢幕 |
| 界面 | 分界面（物理） | interface | interface → 介面 |

判斷技巧：看到「文件」時，先確認指的是 document 還是 file。這一組是最常見的錯誤來源。

## 14. 標點與符號差異

| 避免 | 使用 |
|---|---|
| “英文彎引號” | 「直角引號」 |
| ‘單引號’ | 『內層直角引號』 |
| 半形逗號分隔並列詞 | 全形頓號「、」 |
| 三個半形句點 `...` | 刪節號「……」 |
| 單一破折號 `—` | 破折號「——」 |

中國常用「“”」作為引號，台灣正體中文出版與技術文件慣用「」。

「單一破折號 `—`」列的是**句子內**插入補充時的用法；標題中以單一 em dash 分隔標籤與說明（如「Pass 1 — Structure」）不在此列，見 `SKILL.md` §14.5。

## 15. 審查方式

審查文件是否混入中國用語時，可用下列指令搜尋高頻詞：

```bash
rg -n '軟件|硬件|網絡|數據庫|信息|默認|缺省|接口|內存|硬盤|服務器|用戶|賬號|打印|存儲|緩存|隊列|線程|進程|字符|數組|對象|變量|循環|遞歸|算法|異常|源代碼|調試|兼容|集成|鏡像|集群|端口|帶寬|分辨率|屏幕|鼠標|菜單|刷新|卸載|激活|視頻|音頻|智能|文檔|質量|項目' .
```

命中結果需逐一判斷：部分詞在台灣也合法使用，只是語意不同（見 §1 同形異義詞）。

搜尋簡體字（排除本檔案，因為比對樣式本身含有這些字元）：

```bash
rg -n '国|个|们|这|发|后|术|应|资|设|计|开|关|网|数|据|时|间|实|现|经|过|问|题' -g '!references/taiwan-terms.md' .
```
